# 演示步骤

先按 README 启动合成示例。示例的几何图片只用来验证流程，没有真实搭配效果。

1. 打开「我的衣橱」，说明衣物按类别保存，每件有固定编号。
2. 打开蓝色示例上衣的详情，点它关联的搭配，展示衣物和搭配之间的关系。
3. 回到「我的衣橱」，切换「未用到」。示例夹克没有用于示例搭配，会出现在这里。
4. 展示外部聊天或维护命令。网页本身没有照片上传或 AI 生成按钮，不能在演示中声称有这些功能。
5. 如需展示「准备丢弃」，从当前数据库查询示例夹克的编号，再使用 README 对应服务地址和维护说明里的状态命令。只操作示例数据库。

使用真实衣物录制时，先检查图片是否还原原款。AI 图用于比较搭配，不能验证尺寸、面料或真实合身程度。
