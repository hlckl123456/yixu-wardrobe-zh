# 用合成数据演示

先按 [README](../README.md#先看一个合成示例)启动示例。示例只包含三张几何图、一套没有配图的搭配，不会显示作者的真实衣物。

## 建议的浏览顺序

1. 打开「我的搭配」。示例搭配列出了它引用的蓝色上衣和灰色长裤。这里的列表会保留保存顺序；季节和风格按钮只改变当前筛选。
2. 打开「我的衣橱」。点蓝色上衣，查看衣物详情，再从详情进入关联搭配。棕色夹克没有被这套搭配引用，可以用「未用到」筛选找到它。
3. 打开「衣橱概览」，看类别和色系统计。再用右上角调色盘切换页面配色。
4. 打开「随心配」。这里应显示空状态，因为示例搭配没有配图。要演示四套一批和「换一批」，需要另外保存至少五套有配图、所用衣物仍在用的搭配。

「准备丢弃」可以从衣橱进入。若要在示例里演示状态变化，先用 `lookup-codes.mjs` 查准夹克编号，再对示例服务运行[状态维护命令](MAINTENANCE.md#常用维护命令)。不要对自己的正式衣橱试运行示例命令。

网站不会在页面里上传照片或生成搭配。录入与生成应作为外部工具和维护命令的过程单独展示。真实衣物的 AI 图还需要与原物核对；图片不能证明尺寸、面料或合身度。
