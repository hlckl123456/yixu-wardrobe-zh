# 演示步骤

先按 README 启动合成示例。示例的几何图片只用来验证流程，没有真实搭配效果。

1. 在「我的搭配」查看已保存的示例搭配。真实衣橱有更多搭配时，季节和风格按钮会直接筛选，保存顺序不变。
2. 打开「随心配」，切换心情与季节。合成示例只有一套，换批按钮会停用；四套一批的效果需要更多已保存搭配。
3. 打开「我的衣橱」，按类别浏览带固定编号的衣物。点开蓝色示例上衣，再进入它关联的搭配。
4. 在衣橱的筛选中查看「未用到」；示例夹克会出现在这里。「衣橱概览」显示类别与色系图表，右上角调色盘可以切换四种页面配色。
5. 展示外部聊天或维护命令。网页本身没有照片上传或 AI 生成按钮，不能在演示中声称有这些功能。
6. 如需展示「准备丢弃」，从当前数据库查询示例夹克的编号，再使用 README 对应服务地址和维护说明里的状态命令。只操作示例数据库。

使用真实衣物录制时，先检查图片是否还原原款。AI 图用于比较搭配，不能验证尺寸、面料或真实合身程度。
