# 衣序

衣序用来整理你自己的衣服和搭配。衣物照片、搭配记录都存在你的电脑上；打开搭配时，你能找到它用的是衣橱里的哪几件。

这是可自行运行的源码版。刚下载时衣橱是空的，不包含作者的照片和搭配数据。[English version](https://github.com/hlckl123456/yixu-wardrobe-en)。

## 打开后能做什么

- **我的搭配**：按保存顺序看搭配，直接点选季节和风格。打开一套搭配，可以查看它用了哪些衣物。
- **随心配**：从已保存、有配图、所用衣物仍在用的搭配中随机取最多四套。选好心情和季节后，可以继续换一批；本轮没看过的搭配会优先出现。
- **我的衣橱**：按类别、子类和搭配引用次数找衣服。从一件衣服可以进入用到它的搭配；「衣橱概览」显示类别和色系。准备丢弃的衣物单独放在衣橱的次级入口，档案仍保留。
- **调色盘**：在页面右上角切换暖米、粉、蓝、绿四种配色。

待购搭配也可以保存，但必须标明哪些单品还没买。它们不会被算作已有衣物。

## 在本机运行

需要 Node.js 24 或更新版本。日常启动不需要安装额外的 npm 依赖。

```sh
git clone https://github.com/hlckl123456/yixu-wardrobe-zh.git
cd yixu-wardrobe-zh
npm start
```

在浏览器打开 [http://127.0.0.1:4183/#outfits](http://127.0.0.1:4183/#outfits)。想确认服务是否在运行，输入 `npm run status`；结束时输入 `npm stop`。停止服务不会删除衣橱。

macOS 也可以双击 `启动衣橱.command` 和 `停止衣橱.command`。启动器找不到 Node 时，可用 `YIXU_NODE_BIN` 指向已安装的 Node。

## 先看一个合成示例

示例只有三件用几何图形制作的衣物和一套没有配图的搭配。它适合用来检查衣物详情、搭配关联和衣橱概览；由于搭配没有配图，「随心配」不会显示它。示例目录必须是一个尚未创建的新目录。

```sh
npm run demo -- "$PWD/demo-data"
YIXU_DATA_DIR="$PWD/demo-data" node scripts/local.mjs start 4193
```

打开 [http://127.0.0.1:4193/#outfits](http://127.0.0.1:4193/#outfits)。看完后停止示例服务：

```sh
YIXU_DATA_DIR="$PWD/demo-data" node scripts/local.mjs stop 4193
```

上面的环境变量写法适用于 macOS 和 Linux。Windows 用户可以先在 PowerShell 中设置 `$env:YIXU_DATA_DIR`，再运行相同的 Node 命令。更具体的浏览顺序见[演示说明](docs/DEMO.md)。

## 把自己的衣服放进去

网站目前负责浏览，不提供照片上传或网页内编辑。你可以用自己选择的工具整理照片，再通过本项目的维护命令录入。一个常见流程是：

1. 拍摄衣物、去背景，并检查处理后的图片。AI 补全被遮挡的地方时，要先确认结果并记录处理方式。
2. 按[维护说明](docs/MAINTENANCE.md)准备衣物资料，用 `scripts/intake.mjs` 录入。
3. 基于已有衣物制作并审核搭配图，再用 `scripts/save-owned-outfit.mjs` 保存想穿的搭配。

你可以在 Codex 或其他外部工具里讨论搭配，但本项目不内置模型调用，也不会在点击「换一批」时生成新搭配。「未用到」和「仅用在 1–2 套」统计的是搭配引用，不是实际穿着次数。

## 数据放在哪里

默认数据目录是仓库内不会被 Git 跟踪的 `private-data/`。你也可以把 `YIXU_DATA_DIR` 设为另一个绝对路径。数据库、图片和备份不要提交到 GitHub。

服务只监听 `127.0.0.1`，面向单人本机使用；它没有账号和公网部署所需的权限管理。中英文仓库各自运行，数据不会自动同步。详见[安全说明](SECURITY.md)。
