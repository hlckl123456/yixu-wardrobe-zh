# 衣序

**先看看衣柜里已经有什么，再决定今天穿什么。**

我做衣序，是因为衣服买了不少，出门前却总在穿那几件。我把自己拍的衣服照片整理进衣橱，让 Codex 帮我提出搭配候选；裤子不合适就换，整套不喜欢就删。衣序留下我确认过的衣服和搭配，想穿的时候可以再找出来。

这个仓库是可自行运行的**中文版源码**。[English version](https://github.com/hlckl123456/yixu-wardrobe-en) 也已公开。下载后是空衣橱，里面没有我的照片、搭配或私人记录。

## 用起来是什么样

| 页面 | 可以做什么 |
| --- | --- |
| 我的衣橱 | 看自己录入的上装、下装、鞋和配饰；点开一件衣服，可以找到用到它的搭配。还能按「未用到」和「仅用在 1–2 套」筛选，或查看类别和色系概览。 |
| 我的搭配 | 按保存顺序浏览自己留下的搭配，直接按季节和风格筛选。 |
| 随心配 | 选季节和想穿的感觉，一次看最多四套。没喜欢的就换一批；同一轮会优先给你没看过的搭配。 |

页面右上角有调色盘，可以切换暖米、粉、蓝、绿四种配色。「准备丢弃」的衣服留在衣橱的次级入口，记录不会因为移到那里就消失。

衣序展示的是**已经保存的搭配**。「换一批」会从符合条件的搭配中随机选取，不会临时调用 AI 生成新搭配。照片整理和搭配构思可以借助 Codex 或其他外部工具；最后保存哪套，由你决定。

## 先看一个合成示例

需要 Node.js 24 或更新版本。日常运行不用额外安装 npm 依赖。下面的示例只含三件几何图形衣物和一套无配图的搭配，不含我的私人数据。

```sh
git clone https://github.com/hlckl123456/yixu-wardrobe-zh.git
cd yixu-wardrobe-zh
npm run demo -- "$PWD/demo-data"
YIXU_DATA_DIR="$PWD/demo-data" node scripts/local.mjs start 4193
```

打开 [合成示例](http://127.0.0.1:4193/#outfits)，可以查看衣物、搭配之间的关联，以及衣橱概览和调色盘。示例搭配没有图片，所以「随心配」会显示空状态。演示四套一批的效果需要先保存有配图的搭配，具体顺序见[演示说明](docs/DEMO.md)。

看完后停止示例服务：

```sh
YIXU_DATA_DIR="$PWD/demo-data" node scripts/local.mjs stop 4193
```

`demo-data/` 已被 Git 忽略。示例命令中的数据目录须是尚未创建的新目录；它不会覆盖现有衣橱。

上面的环境变量写法适用于 macOS 和 Linux。Windows PowerShell 用户可以先设置 `$env:YIXU_DATA_DIR = "$PWD/demo-data"`，再运行相同的 `node scripts/local.mjs` 命令。

## 建立自己的衣橱

从空衣橱开始，运行：

```sh
npm start
```

然后打开 [本机衣橱](http://127.0.0.1:4183/#outfits)。服务只监听 `127.0.0.1`。可用 `npm run status` 检查运行状态，用 `npm stop` 结束；停止服务不会删除衣橱。macOS 也可以双击 `启动衣橱.command` 和 `停止衣橱.command`。如果启动器找不到 Node，可用 `YIXU_NODE_BIN` 指向已安装的 Node。

网页负责浏览，目前没有照片上传或编辑按钮。把自己的衣服放进去，需要按下面的顺序准备：

1. 拍摄衣服，制作去背景图片，并对照原图核对颜色和款式。若 AI 补全了照片里看不见的部分，还要确认并记录处理方式。
2. 按[维护说明](docs/MAINTENANCE.md#录入衣物)准备衣物资料，用 `scripts/intake.mjs` 录入。
3. 用已有衣物制作搭配候选，自己挑选并检查搭配图，再用 `scripts/save-owned-outfit.mjs` 保存想穿的搭配。

保存后就能在「我的搭配」里找到它。只有带配图、所用衣物仍在用的普通搭配，才会进入「随心配」。待购搭配也可以保存，但待购单品会明确标出，不会算作衣橱里的现有衣服。

## 照片和记录在哪里

默认数据放在仓库内、不会被 Git 跟踪的 `private-data/`。你也可以把 `YIXU_DATA_DIR` 设为另一个绝对路径。数据库、照片和备份留在你的电脑上，不要提交到 GitHub。

这个项目面向单人本机使用，没有账号、多人权限或公网部署所需的访问控制。中英文仓库的数据目录相互独立，不会自动同步。详情见[安全说明](SECURITY.md)。「未用到」和「仅用在 1–2 套」统计的是保存的搭配引用，不是实际穿着次数。
